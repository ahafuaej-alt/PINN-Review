Current citation guidance

The first formal Atlas release is v2026.09.1, dated 2026-09-25. For reproducible academic use, cite that release and retain the exact Git tag or commit SHA associated with the state used in your analysis.

Release citation:
Alhaj Hasan, A. F. PINN Review Atlas, version v2026.09.1, 2026. DOI: 10.5281/zenodo.22958038.

Formal reproducible release

The first formal publication/reproducibility snapshot is v2026.09.1, released on 2026-09-25. This Atlas-level release identifier is separate from component dataset versions such as the Master Bibliography and PINN Realm version 2.3.1 and Frameworks version 3.0.0.

The exact v2026.09.1 snapshot is archived on Zenodo with version-specific DOI 10.5281/zenodo.22958038. Use this DOI when citing or reproducing this exact release. The persistent Zenodo Concept DOI for the evolving Atlas will be added once its value is confirmed.

How to cite reproducibly

Atlas as a wholeFor the exact v2026.09.1 release, use DOI 10.5281/zenodo.22958038; retain the release identifier for reproducibility.
Exact research stateRecord the Atlas release identifier or exact Git commit SHA used for the analysis.
Specific Atlas resultLink to the narrowest relevant page, figure, table, formulation, paper profile, comparison, or dataset view rather than only the Atlas home page.
Downloaded materialKeep the originating page URL and release/commit identifier with exported CSV, JSON, SVG, PNG, or other derived files.
Component dataWhere relevant, retain the component dataset version or snapshot date in addition to the Atlas-level release identifier.

Machine-readable citation

The repository includes a root CITATION.cff file. GitHub uses this metadata to provide its Cite this repository interface. The file identifies the released Atlas version as v2026.09.1 with release date 2026-09-25. The version-specific Zenodo DOI 10.5281/zenodo.22958038 is recorded in the citation metadata.

Release policy

Atlas releases follow the date-based convention vYYYY.MM.N. Each formal release is intended to resolve to an immutable Git tag and exact commit SHA so that a published result can be reconstructed from the same repository state. See RELEASE.md ↗ for the complete release and reproducibility policy.
